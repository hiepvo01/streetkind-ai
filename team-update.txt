  calling raw '/api/...' paths and bypassed the apiUrl() helper. In

  both remotes redeployed; verified working.

  encounteredBy.self was being set to true for "I'm helping..." narration
  even after your prompt update. Tightened the prompt to direct the model
  to skAmbassador for ambiguous "I helped" / "I noticed" / "we found"
  cases. Fixed in commit ef39215.

Post-merge issues that needed fixing on top of your branch:

  None directly attributable to !7.

  Indirect: my age_group config-drift fix (commit ef39215) removed the
  "from"-prefix from shared.json's age_group keys to match the client
  schema. That broke SafeBase because GenderAgeCount uses the
  from-prefixed keys. Fixed by adding an age_group override in
  safebase.json so SafeBase keeps the "from" prefix while client/incident
  use the unprefixed shared keys (commit 1624319).


Other things found in the deep audit (not from your MRs but worth knowing)
---------------------------------------------------------------------------

A code review of the audio + transcript pipeline turned up four more
silent field-binding bugs in the Client form, identical pattern to the
age_group bug. The frontend tab read a typo'd or phantom field name
while the schema used the right one. Affected production records:

  emergencyServicesCalled         ~454 records  (was data.emergencyServices)
  clientServiceReferrals           ~94 records  (was data.serviceReferrals)
  clientConsciousness/Visibility/LostProperty   ~688 records  (phantom data.theftRisk.*)
  injury                          ~1203 records  (was data.injuryRisk)

All fixed in commit 1624319 + bb24aea. The radio/checkbox values now
render correctly when you open any of those clients.

Plus a few smaller audit items shipped in the same round:
  - Yellow "Audio recording disabled" warning when the mic is denied
    (likely cause of your "have no voice record" report).
  - <audio> shows a fallback message when the signed URL is unavailable.
  - Transcripts fetch error is now visible instead of showing a fake
    "no transcripts" state.
  - 67 legacy clients with `safeBase` blob (lower-case b) now display
    correctly via a read-side normaliser.
  - 4597 client records had a `startTime` Pydantic was silently
    dropping on PUT. Schema field added.
